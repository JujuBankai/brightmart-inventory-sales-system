BrightMart Inventory & Sales Management System
Project Overview
BrightMart is a small-business Inventory and Sales Management System developed as part of the MANCOSA Higher Certificate in Coding Integrated Coding Project.

The prototype provides functionality for managing products and suppliers, recording sales transactions, automatically updating stock quantities, identifying low-stock products, and generating basic sales and inventory reports.
