# BrightMart Inventory & Sales Management System

## Project Overview

BrightMart is a small-business Inventory and Sales Management System developed as part of the MANCOSA Higher Certificate in Coding Integrated Coding Project.

The prototype provides functionality for managing products and suppliers, recording sales transactions, automatically updating stock quantities, identifying low-stock products, and generating basic sales and inventory reports.

## Technologies Used

- Python
- Tkinter
- SQLite
- Visual Studio Code

## Main Features

- User authentication
- Password hashing
- Role-based access
- Product CRUD operations
- Supplier CRUD operations
- Sales transaction processing
- Automatic stock deduction
- Insufficient-stock validation
- Low-stock warnings
- Inventory reporting
- Daily sales reporting
- Seven-day sales reporting

## User Roles

### Store Manager

- Products
- Suppliers
- Record Sale
- Inventory / Low Stock
- Reports

### Sales Staff

- Record Sale
- Inventory / Low Stock

### Business Owner

- Inventory / Low Stock
- Reports

## Database

The SQLite database contains the following tables:

- USER
- SUPPLIER
- PRODUCT
- SALE
- SALE_ITEM

## Running the Prototype

Run the application with:

`python main.py`

The BrightMart login screen will open.
